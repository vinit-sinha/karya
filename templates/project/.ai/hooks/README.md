# AI Hook Definitions

Place hook descriptions and scripts here for pre- or post-processing.

## Structure

- Use plain markdown or executable shell scripts
- Describe when a hook should run and what it does
- Keep hooks small and composable

## Example

- `.ai/hooks/pre-publish.sh`
- `.ai/hooks/post-create.md`

## Notes

Hooks can be used to integrate tooling, validation, environment setup, or cleanup steps.
