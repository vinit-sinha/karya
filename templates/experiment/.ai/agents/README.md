# AI Agent Configurations

Use this directory for agent definitions, workflows, and orchestration metadata.

## Structure

- Each agent may have a separate markdown file
- Include supported tools, skills, and invocation examples
- Keep configuration human-readable and easy to extend

## Example

- `.ai/agents/codex-agent.md`
- `.ai/agents/analysis-agent.md`

## Notes

This directory is intended for higher-level agent configuration, not raw prompts.
