# starter-code

Upstream source provided by the course — treat as **read-only reference**.

Clone or copy external repos here (lab skeletons, course kernels, starter repos). Never commit your own changes on top of upstream files; create a working branch or copy files to `work/` instead.

```bash
# Clone an upstream repo into this directory
git clone <upstream-url> starter-code/<repo-name>

# Start a working branch inside the cloned repo
cd starter-code/<repo-name>
git checkout -b work/<lab-name>
```
