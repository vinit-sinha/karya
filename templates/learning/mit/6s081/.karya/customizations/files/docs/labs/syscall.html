Karya workflow notes

✓ Starting this lab

Use the VS Code task Lab: start and pick syscall. This checks out the syscall branch in your xv6 repo and creates work/syscall/notes.md for your notes.

✓ Wherever MIT says "clone the repo"

Your xv6 source is already at starter-code/xv6-labs-2021/ — a private GitHub mirror managed by Karya. You don't need to clone from MIT.

✓ Wherever MIT says "make handin"

Use the VS Code task Lab: done instead. It runs make grade, creates your writeup, and pushes to your private repo. No MIT account or API key needed.
