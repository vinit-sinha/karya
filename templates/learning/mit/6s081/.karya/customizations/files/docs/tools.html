Setting up your RISC-V development environment

Karya users: If you created this project with karya create project --uri kosh://learning/mit/6s081, the toolchain and QEMU were installed automatically. Jump straight to Verify your installation.

For this course you need RISC-V versions of: QEMU 5.1+, GDB 8.3+, GCC, and Binutils.

macOS

MIT original

Install developer tools:

$ xcode-select --install

Install Homebrew:

$ /usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"

Install RISC-V compiler toolchain:

$ brew tap riscv/riscv
$ brew install riscv-tools

Add to your shell rc file:

PATH=$PATH:/usr/local/opt/riscv-gnu-toolchain/bin

Install QEMU:

$ brew install qemu
✓ Karya — macOS

Karya's post-create hook installs everything automatically. If you need to do it manually:

$ xcode-select --install
$ /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

The tap name changed — use the current one:

$ brew tap riscv-software-src/riscv
$ brew install riscv-gnu-toolchain
$ brew install qemu

No manual PATH change needed — Homebrew wires this up automatically on Apple Silicon and Intel Macs.

Windows

MIT original

Install Windows Subsystem for Linux, then Ubuntu 20.04 from the Microsoft Store.

$ sudo apt-get update && sudo apt-get upgrade
$ sudo apt-get install git build-essential gdb-multiarch qemu-system-misc \
    gcc-riscv64-linux-gnu binutils-riscv64-linux-gnu

Access WSL files at \\wsl$\Ubuntu-20.04\home\<username>\

✓ Karya — Windows

Same approach — WSL2 is required. Enable it from PowerShell (as administrator):

wsl --install

Then open an Ubuntu terminal and install karya inside WSL. All karya commands and templates work as-is under WSL2.

The apt-get command from MIT works unchanged inside WSL2 Ubuntu.

Debian / Ubuntu (native)

$ sudo apt-get install git build-essential gdb-multiarch qemu-system-misc \
    gcc-riscv64-linux-gnu binutils-riscv64-linux-gnu
✓ Karya — Linux

The command above works as-is. Karya's post-create hook runs it automatically on Debian/Ubuntu.

Arch Linux

$ sudo pacman -S riscv64-linux-gnu-binutils riscv64-linux-gnu-gcc \
    riscv64-linux-gnu-gdb qemu-arch-extra

You don't have MIT Athena access. Install locally using one of the OS-specific methods above.

Running a Linux VM (fallback)

If local install isn't working, use a VM:

  • VirtualBox — free, works on Mac/Linux/Windows
  • VMware Player — free for Linux/Windows

Download an Ubuntu Desktop ISO, create a VM, then follow the Debian/Ubuntu instructions above.

Verify your installation

Boot xv6 in QEMU:

# From the xv6 source directory:
$ cd starter-code/xv6-labs-2021
$ make qemu
# ... lots of output ...
init: starting sh
$
# Quit QEMU with: Ctrl-a  then  x
✓ Karya — use VS Code task

Instead of typing the command, use the VS Code task:
Cmd+Shift+P → Tasks: Run Task → xv6: boot (make qemu)

Check versions:

$ qemu-system-riscv64 --version
QEMU emulator version 5.1.0 (or newer)

$ riscv64-unknown-elf-gcc --version
riscv64-unknown-elf-gcc (GCC) 10.1.0 (or newer)

If xv6 boots and you see the $ prompt, you're ready. Start with Lab: Utilities.
