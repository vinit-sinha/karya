About this course

6.S081 teaches the fundamentals of operating systems through hands-on implementation in xv6 — a small Unix-like kernel running on RISC-V. You will implement real OS features: system calls, page tables, traps, copy-on-write fork, multithreading, a network driver, a file system, and memory-mapped files.

This is the self-learner edition of the MIT Fall 2021 course. MIT-specific steps (Athena, Piazza, handin) are replaced with Karya equivalents.
