# AI Skill Definitions

Place skill descriptions and instruction files here.

## Structure

- Each skill can be a separate markdown file
- Use human-readable titles and sections
- Include examples of when the skill should be used
- Define tool requirements: Specify which tools are necessary for the skill.

## Schema
Each skill should define its **Context**, **Constraints**, and **Expected Output**. This allows the Agent to understand the boundaries of its capabilities.

## Example

- `.ai/skills/analysis.md`
- `.ai/skills/refactor.md`
- `.ai/skills/resume-work-state.md`

## Notes

This directory is intended for tool/agent skill metadata rather than executable code.
