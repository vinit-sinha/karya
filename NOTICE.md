# Naming note

This project's name, "karya," is independently coincidental with [Karya](https://karya.in), a Bengaluru-based nonprofit providing dignified digital work (AI data annotation, dataset generation) to economically disadvantaged communities in India. This repository is unrelated to that organization, its platform, or its work — no affiliation, endorsement, or connection exists between the two.

"Karya" (कार्य) is a common Sanskrit/Hindi word meaning "work" or "task," which likely explains the independent overlap. Given their earlier, more prominent use of the name in the same broad technology space, this project may be renamed before any public release.
